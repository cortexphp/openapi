## Requirements

- PHP 8.4+

## Installation

```bash
composer require cortexphp/openapi
```

## YAML Output

JSON serialization (`toJson()`, `toArray()`) is built-in. YAML output requires [symfony/yaml](https://symfony.com/doc/current/components/yaml.html):

```bash
composer require symfony/yaml
```

`toYaml()` throws a `RuntimeException` if the package is not installed.

## Development Setup

### For Package Development

If you're contributing to the package or want to run tests:

<Steps>
  <Step title="Clone the Repository">
    ```bash
    git clone https://github.com/cortexphp/openapi.git
    cd openapi
    ```
  </Step>
  <Step title="Install Dependencies">
    ```bash
    composer install
    ```
  </Step>
  <Step title="Run Tests">
    ```bash
    composer test
    ```
  </Step>
  <Step title="Run Tests and Code Quality Tools">
    ```bash
    composer check
    ```
  </Step>
</Steps>
